## 1. 产品概述

牙科耗材订货助手是一款面向牙科耗材供应商业务员的桌面端工具，重点服务上门拜访和电话跟单场景。通过整合客户档案、智能选品、报价生成和回访提醒，帮助业务员减少翻阅聊天记录的时间，降低漏单率，提高下单效率。

- 目标用户：牙科耗材供应商的一线业务员
- 核心价值：一站式客户信息整合 + 病例场景驱动的智能选品 + 自动补货提醒，减少漏单、提升跟单效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 业务员 | 管理员分配账号 | 查看客户档案、下单、生成报价单、管理回访提醒 |
| 管理员 | 系统初始化 | 业务员全部权限 + 品类管理、赠品政策配置、数据统计 |

### 2.2 功能模块

1. **工作台**：今日待办回访提醒、快捷入口、近期订单动态
2. **客户档案**：诊所信息总览、常用耗材清单、历史偏好品牌、未结清订单、上次采购日期
3. **下单中心**：病例场景选品输入、智能品类推荐、逐项确认数量/价格/赠品
4. **报价确认**：生成订货确认单、含税价展示、配送方式、欠货说明、付款提醒、一键复制
5. **回访提醒**：高频耗材用完日期预测、弹窗/列表提醒、一键生成补货单

## 3. 核心流程

**主流程：业务员跟单下单**

业务员打开应用 → 查看工作台今日提醒 → 选择客户进入档案 → 了解采购历史和偏好 → 点击下单进入下单中心 → 输入病例场景数据 → 查看智能推荐品项 → 逐项确认数量和价格 → 进入报价确认 → 核对含税价和配送方式 → 生成确认单并复制发给诊所 → 订单创建完成

**回访提醒流程：**

系统根据高频耗材消耗周期计算预计用完日期 → 到期前3天生成提醒 → 业务员在工作台或提醒页面查看 → 联系诊所确认补货 → 直接创建补货订单或标记延后

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0D7377) 作为品牌色，传达专业医疗感；暖橙 (#E8843C) 作为强调色，用于提醒和关键操作
- **辅助色**：浅灰底 (#F5F6FA)、白色卡片、深灰文字 (#1E293B)
- **按钮风格**：圆角 8px，主操作实色填充，次操作描边
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- **图标风格**：线性图标（Lucide），统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 今日提醒卡片 | 左侧彩色竖条标识紧急程度，右侧显示诊所名和品项，悬停展开详情 |
| 工作台 | 快捷操作 | 3个圆形图标按钮，含图标+文字标签，悬停微上浮 |
| 工作台 | 近期动态 | 时间线列表，左侧时间轴圆点+连线，右侧状态标签（已发货/待确认等） |
| 客户档案列表 | 搜索栏 | 顶部固定搜索框，带筛选下拉 |
| 客户档案列表 | 客户卡片 | 白色圆角卡片，左侧诊所名+地址，右侧关键指标数字 |
| 客户档案详情 | 信息面板 | 顶部诊所名+标签页切换（概览/耗材/品牌/订单） |
| 客户档案详情 | 常用耗材 | 表格+进度条（显示消耗进度） |
| 客户档案详情 | 品牌偏好 | 横向条形图，品牌名+占比 |
| 客户档案详情 | 未结清订单 | 订单卡片，含状态徽章 |
| 下单中心 | 场景输入区 | 3列数字输入框，每列带图标和标签（种植/正畸/洁牙），下方滑块辅助 |
| 下单中心 | 推荐品项列表 | 卡片列表，每项左侧品类图标+名称，右侧数量调整器和价格 |
| 下单中心 | 赠品标签 | 小型彩色标签显示适用的赠品政策 |

### 4.3 响应式设计

- 桌面优先设计，最小适配宽度 1280px
- 侧边导航栏在 1280-1440px 区间可折叠为图标模式
- 内容区使用弹性布局，卡片网格自动适配列数
